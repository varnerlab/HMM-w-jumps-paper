% Single paragraph. The multi-asset variance correction is the main
% contribution; the HMM-WJ result is presented as validation of the
% marginal component rather than as a uniformly superior generator.

Synthetic multi-asset paths must preserve both per-asset return
distributions and their relationship with the market. Directly
inserting a full-return generator draw into a single-index model
double counts market variance and distorts the composed marginal. We
derived a closed-form scale correction for this problem and evaluated
it on $423$ non-market tickers in a $424$-asset US equity and
exchange-traded-fund universe. The correction recovered each ticker's
calibrated factor loading to a median absolute error of $0.018$ while
producing median excess kurtosis of $7.2$ and a Hill index of $0.365$.
Residual models fitted directly to each ticker had KS pass rates of
$67$--$76\%$, compared with $50\%$ for the corrected method. Their
one-day $99\%$ VaR exceedance rates were $0.99$--$1.09\%$, compared
with $0.95\%$ for the corrected method, which did not require a
separate residual fit. The per-asset input was a hidden Markov model
with Laplace-quantile states and Student-$t$ emissions. Its
jump-duration variant (HMM-WJ) used Poisson episodes to lengthen
tail-state visits. On SPY, HMM-WJ had a $97.6\%$
in-sample KS pass rate and reduced absolute-growth autocorrelation
error from $0.059$ to $0.052$ relative to the no-jump variant, while
GARCH reached $0.031$. We selected HMM-WJ as the marginal component
based on this tradeoff, not because it was uniformly superior. The
multi-asset construction still omits cross-asset residual
covariance, so independent residuals can overstate diversification
gains under daily rebalancing. Code and per-asset fitted marginals are
released with the paper.
