---
name: Respond quickly, don't over-plan
description: User wants fast action, not lengthy analysis before editing
type: feedback
---

Act fast. Don't spend long periods reading and planning before making edits. The user noticed multiple times when responses took too long ("did you die?", "you are really thinking...or are you just hanging out?").

**Why:** User prefers rapid iteration. Read what's needed, make the edit, move on.

**How to apply:** When the user asks for an edit, do it immediately. Don't read the entire file if you only need the relevant section. Don't map every gap before starting — fix them one at a time or in quick parallel batches.
