---
name: Connective tissue between sections and paragraphs
description: User wants transition sentences between subsections and between paragraphs within sections
type: feedback
---

Always add one well-crafted transition sentence between subsections (at the end of the preceding subsection) and between paragraphs within a section. The paper should read as one continuous argument, not a collection of disconnected blocks.

**Why:** User identified the related work, results, and discussion as feeling "disconnected" without bridges. A single sentence can make all the difference.

**How to apply:** When writing or restructuring sections, check every paragraph/subsection boundary for a bridge sentence. Place transitions at the end of the preceding paragraph/subsection, so the next heading starts clean.
