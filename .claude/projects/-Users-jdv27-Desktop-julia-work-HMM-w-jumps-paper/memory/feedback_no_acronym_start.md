Never start a sentence with an acronym (e.g., "GANs have been..." should be "Generative adversarial networks (GANs) have been...").

**Why:** User explicitly corrected this in the related work section.

**How to apply:** When writing or editing paper text, check sentence openings for acronyms and expand or restructure.
